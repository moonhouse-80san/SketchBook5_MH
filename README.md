# SketchBook5 게시판 스킨 — 문하우스 수정버전 (sketchbook5 MH V3.9)

스케치북5 게시판 스킨을 라이믹스 2.x · PHP 8.4에서 쓰도록 문하우스에서 손본 판입니다. 한국형 게시판 스타일과 여러 목록 유형, 모바일 대응을 그대로 유지합니다.

| 항목 | 내용 |
| --- | --- |
| 종류 | 게시판 스킨 |
| 버전 | 3.9.0 (2026-11-21) |
| 설치 경로 | `/modules/board/skins/sketchbook5_MH` (또는 기존 `sketchbook5`에 덮어쓰기) |
| 자료실 | https://moonhouse.co.kr/xemy/590994 |
| 적용 예 | https://moonhouse.co.kr/xemy |
| 원본 | SketchBook5 (sketchbook5, hareweb) |
| 라이선스 | GPL v2 |

## 설치 — 두 가지 방법 중 하나

### 방법 1. 새 스킨으로 올리기 (권장)

1. 압축을 풀어 폴더 이름을 `sketchbook5_MH` 로 둡니다.
2. `/modules/board/skins/sketchbook5_MH` 에 업로드합니다.
3. 관리자 > 게시판 > 스킨 선택에서 **sketchbook5 MH V3.9** 를 고릅니다.
4. 관리자 > 캐시파일 재생성.

### 방법 2. 기존 스케치북5 폴더에 덮어쓰기

1. **먼저 기존 스킨을 백업합니다.** (필수)
2. `/modules/board/skins/sketchbook5` 에 모든 파일을 덮어씁니다.
3. 스킨 이름이 `sketchbook5` 그대로이므로 이미 쓰던 게시판은 설정이 유지됩니다.
4. 관리자 > 캐시파일 재생성.

> ⚠ 두 방법의 폴더 이름이 다릅니다. 자료실 게시물의 "설치경로"는 `sketchbook5_MH`, README의 예전 안내는 `sketchbook5` 덮어쓰기였습니다. **둘 다 동작하며**, 새로 올리면 `sketchbook5_MH`, 덮어쓰면 `sketchbook5`로 남습니다. 한 사이트에서 두 폴더를 동시에 쓰면 같은 스킨이 두 개로 보이니 하나만 두세요.

## 주요 기능

- 목록 유형: 기본(normal), 웹진(webzine), 갤러리(gallery), 클라우드 갤러리(cloud_gall), 첫 글만 썸네일(firstthumb), 북 갤러리(book_gallery), 거래장(books), 방명록(guest), FAQ, 유튜브, 더블(double), 모바일형(m), mb
- 게시판 설정 위저드 (`_wizard.php`, `_wizardsetting.html`) — 설정을 단계별로 고를 수 있습니다.
- 스킨 자체 버전 표시와 모듈번호 표시 옵션
- 폰트어썸·Sexy Button 사용 형태 선택 (Web Fonts 애드온과 연동)
- **본문 이미지 테두리 (V3.9)** — 글 작성 화면에서 굵기(0~20px)와 색상을 골라 본문 이미지에 테두리를 넣습니다. 글마다 값을 저장하려고 게시판에 아래 확장변수 3개를 만들어야 하며, 유형은 모두 한 줄 텍스트, 필수 아님입니다.

  | 이름(자유) | 확장변수 ID |
  | --- | --- |
  | 이미지 테두리 굵기 | `img_border_w` |
  | 이미지 테두리 색상 | `img_border_c` |
  | 이미지 테두리 그림자 | `img_shadow` |

  3개가 모두 없으면 옵션이 나타나지 않습니다. 기본 색은 `#ffaa56`이고 굵기 0이면 테두리가 없습니다. 이미지별로 따로 줄 수는 없습니다. (`img_boarder` 모듈을 쓰면 이미지별로 지정할 수 있습니다.)
- 첨부파일 목록 중간에 광고 문구 삽입 (V3.9)
- 첨부파일을 관리자만 삭제하는 버튼 (V3.9)
- 댓글·대댓글, 비밀글, 추천/비추천, SNS 공유, 지도(`map.html`), QR, 태그, D-day, 졸졸이 스토커 등 스케치북5의 기능 대부분 유지
- 모바일 스킨 포함 (`_write_form_mobile.html`, `_list_m.html`)

## 요구 사항

- 라이믹스 2.x
- **PHP 8.4 기준으로 수정**되었습니다. (PHP 8.0~8.3에서도 동작하지만, 가장 최근 검증 환경은 PHP 8.4입니다)
- 폰트어썸·Sexy Button을 쓰려면 `web_fonts` 애드온을 설치하고 활성화하세요.

## XE 1.8에서 쓰기

- XE에서는 그대로 동작하지 않습니다. 자료실 게시물(https://moonhouse.co.kr/xemy/590994) 또는 Q&A(https://moonhouse.co.kr/qa/592023#comment_592049)에 첨부된 **`xe.zip`** 을 풀어 `_read.html`, `list.html`, `write_form.html`, `_write_form_mobile.html` 을 덮어쓰면 동작합니다.
- `xe.zip`은 이 저장소에 들어 있지 않고 게시물 첨부로만 배포됩니다.
- XE 버전·PHP 버전에 따라 정상 동작하지 않을 수 있으니 테스트 후 적용하세요.

## 최근 변경 (V3.9 / 2026-11-21)

- 첨부 파일 목록 중간 광고 문구 삽입 (`_read_data.html`, `skin.xml`)
- PHP 8.4 이상에서 오류가 날 수 있는 파일 수정
- 레이아웃에 따라 `<input>` 버튼 정렬이 어긋나는 문제 수정 (`css/board.css`)
- 첨부 파일을 관리자만 삭제하는 버튼 추가
- 본문 이미지 테두리 기능 추가 (위 확장변수 3개 필요)
- 설정 위저드(Wizard) 수정 — 저장 버튼을 항상 하단에 두고, 저장 후 목록이 다시 열림
- 게시판 상단에 로그인·설정·관리·회원정보·게시물관리 도구 출력
- 글 작성 시 미리 입력된 글의 HTML이 적용되지 않던 버그 수정

## 주의 사항

- 덮어쓰기 전 **백업은 필수**입니다. 스킨을 직접 고쳐 쓰던 사이트라면 수정 내용이 사라집니다.
- 스킨 설정 항목이 450개가 넘습니다. 게시판마다 필요한 항목만 만지고, 공통 설정은 위저드로 한 번에 잡는 편이 편합니다.
- 폰트어썸·Sexy Button을 "외부(애드온이나 레이아웃등)에서 사용"으로 두면 스킨이 아이콘을 불러오지 않습니다. 이때는 `web_fonts` 애드온에서 해당 항목을 켜야 아이콘이 보입니다.
- 스킨 업데이트 후에는 캐시파일 재생성과 브라우저 새로고침(캐시 지우기)을 함께 하세요.
- 원본 스케치북5의 GPL v2 라이선스를 따릅니다. 원저작자 표기를 지우지 마세요.
